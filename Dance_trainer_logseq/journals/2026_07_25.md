- [feature] Per-block inline editing for card notes — clicking a block swaps only that block for an editor, the rest stays rendered — [[Card Notes]]
- [decision] Rejected Obsidian-style live preview (CodeMirror 6 decorations, ~1–2 weeks, weakest on touch) — the complaint was losing your place in the whole-field mode swap, not seeing `**` markers. Per-block editing solves that directly — [[Card Notes]]
- [decision] Block granularity is the `marked` lexer's, so a whole bullet list opens as one editor. Shipped as-is to see whether it actually grates before splitting `list_item`s — [[Card Notes]]
- [fix] Block editor auto-grows instead of scrolling internally — raw markdown is taller than its rendered form, so a fixed-height editor hid most of what you were editing — [[Card Notes]]
- [fix] Escape in a block editor no longer closes the entire card modal — [[Card Notes]]
- [fix] Clicking a second block while one was open opened the wrong block or none — the commit reflows the note between mousedown and click. Resolved on mousedown now, carrying the target as a source offset across the reflow — [[Card Notes]]
- [fix] Block editor closed itself the instant it opened — Vue flushes nextTick before mousedown's default focus action, so the backdrop stole focus and blur-saved. `preventDefault()` on mousedown — [[Card Notes]]
