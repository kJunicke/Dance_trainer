- ## App — known-wrong behaviour
	- TODO Board name still truncates at phone width. Measured 2026-07-21 at 386px: `.board-name` gets 62px for an 85px name. The topbar declutter did *not* fix this (the invite chrome was already hidden under the ≤760px media query, so the win was desktop-only). The only remaining candidate is shrinking `.mode-switch`, which takes 147px against `back-btn` 41 + `search-btn` 40 + `menu-btn` 40 — icons, or a narrower control. See [[UX Batches 2026-07]] Batch 5.
	- TODO Per-action error copy and retry actions on toasts. Every failure currently reads "That didn't go through" with the raw Supabase string underneath. Both need editing the 28 `show()` call sites in `boardStore.ts` (25) and `authStore.ts` (3) — mechanical, and a retry additionally needs the failed operation captured as a callback at each site. See [[UX Batches 2026-07]] Batch 7.
	- TODO Empty columns render as a bare `0` + `+ Add Card`. *"Nothing due today"* is arguably the most valuable sentence this app can say, and it currently shows as blank space.
	- TODO The Practice surfaces have no desktop treatment — `position: fixed; inset: 0` with top-left content and no width media query, so at 1440px they are a full-viewport dark rectangle. Reachable more often since view mode started persisting per board. Either constrain to a centred column above ~700px, or hide the mode toggle on desktop. See [[Practice Companion View]].
	- TODO All contextual help lives in the 22 `title=` attributes, which do nothing on the touch device this is built for.
	- TODO Fenced code blocks (`<pre><code>`) in a note pick up the inline-code rule's background and padding — there's no separate `<pre>` reset. Cosmetic, unnoticed in real use. See [[Card Notes]].
	- TODO The caret can land behind the virtual keyboard (or below the visual viewport) when editing a block that autosizes taller than the screen. `focusAtOffset()` deliberately dropped its own scroll-into-view logic in favour of the browser's default focus scrolling, which only guarantees the *element* is visible, not the caret's line within it — a considered choice, not an oversight, made because the editor no longer has an internal scrollbar to protect. Revisit only if this actually bites in practice. See [[Card Notes]].
- ## Unconfirmed — found by reading, never reproduced
	- Raised 2026-07-25 while writing [[Board View]]. Each was found in the code, none has been seen happen. Confirm in the browser against *Test board* before fixing anything here.
	- TODO Dragging a card **upwards within its own column** may land it one slot below the insertion line. `moveCard` assigns `position = targetPosition` and then re-sorts, so the moved card ties with the card already holding that position, and the stable sort breaks the tie by the order of `cards.value` — i.e. by DB load order, not by the drag. Replaying the store's exact logic in a scratch script on `c0..c4,X` dropping X before `c2` produced `c0,c1,c2,X,c3,c4`. Downward and cross-column drops come out right, cross-column arguably by luck. Fix would be an explicit splice instead of assign-then-sort. See [[Board View]].
	- TODO `insertBoardWithMembership` has no rollback: the board row and its `board_members` row are two separate inserts, so a failure on the second leaves a board that is invisible to everyone including its creator, and undeletable through the UI. See [[Supabase]].
	- TODO `moveCard`'s `applyEnterRule` parameter is dead — it defaults to `true` and no call site passes it. `sweepDueCards()` avoids the on-enter rules by not calling `moveCard` at all. Either drop the parameter or make the sweep use it.
	- TODO `touchDropTarget` isn't refreshed by `autoScrollLoop`, so while the board edge-scrolls under a stationary finger the card insertion line stays drawn in the previous column. Cosmetic: the drop itself is recomputed from scratch on `pointerup`.
	- TODO `cardWriteQueues` is never pruned — one retained promise per card touched in a session. Unbounded, but small.
	- TODO `quickTargetColumns`' doc comment says "in the card modal"; the computed now also feeds the board's quick-drop bar and Session Review's buckets.
